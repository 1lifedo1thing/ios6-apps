# Compass materials

`walnut-source.png` is the selected original 1024-by-1536 walnut material, generated on 2026-10-11 with Codex's built-in image generation tool. It replaces the earlier procedural sine-wave wood texture. It contains no UI, compass, labels, or historical screenshot pixels.

The final production prompt was:

> Create a production bitmap material texture for a faithful iOS 6 compass interface: a beautiful dark American walnut veneer panel photographed perfectly straight on, full bleed edge to edge, portrait aspect ratio approximately 2:3. This is ONLY a flat walnut surface, no compass, objects, text, frame, seams or vignette. Rich deep chocolate brown and amber undertones, finely resolved natural pores, irregular flowing vertical cathedral grain with subtle curls and one understated organic whorl offset toward the left, many narrow changing grain fibers. Genuine polished wood with a restrained satin lacquer, subtle broad even studio illumination from upper left, tangible fine grain and depth, calm darker overall luminance so white system status text remains legible. Inspired by the material realism of Apple's 2012 iOS 6 Compass wood backing. Avoid artificial sine-wave stripes, regular repeating bands, heavy glossy streaks, chunky plank joins, orange oversaturation, scratches, grunge, fantasy illustration and overly distressed antique wood. No UI elements. Sharp texture detail all the way to the edges. Output a high-resolution usable wood texture.

Run `python3 scripts/generate_artwork.py` from the app directory to copy this committed source into `CompassSix/Assets.xcassets/Walnut.imageset/walnut.png` and package the independent `compass-icon-source.png` into `AppIcon.appiconset/compass-icon.png`. The script requires Pillow and does not invoke image generation or need credentials. The bundled walnut is byte-identical to the source. The icon is resized with Lanczos to an opaque RGB 1024-by-1024 PNG, without adding a rounded-square mask; iOS supplies that mask.

Brass turning marks, ivory grain, glass reflection, compass markings, and the raised pivot are drawn in `CompassArtwork.swift`. Their deterministic texture remains fixed between updates. Only the localized direction card rotates; the case and lighting remain stationary. The texture is decorative and hidden from accessibility.

The historical reference and applicable framing rules are linked in the [app README](../README.md) and [shared design language](../../../docs/design-language.md).

## App icon redesign

`compass-icon-source.png` is independent original raster artwork generated with Codex's built-in image generation tool on 2026-10-11. The app icon replaces the earlier programmatic drawing with a thin dark perimeter around a pale calibration band, an ivory face, a slender faceted compass rose, a raised brass pivot, a visible white N inside the red north marker, natural walnut, and the curved upper gloss associated with the classic icon. The system supplies the display mask. Packaging preserves the committed source and exports only an opaque 1024-by-1024 RGB PNG.

The historical layout was cross-checked against Apple's iOS 6 user guide and the upper-left 2009–2013 icon in [Basic Apple Guy's icon history](https://basicappleguy.com/basicappleblog/ios-icon-history). The historical comparison sheet was used only as a visual reference during generation; it is not included in the app or committed as artwork.

The production prompt set is retained below. The initial silver-case interpretation was rejected after the user identified the historical black outer edge. The ten-degree label experiments needed correction and were not selected as finished assets. The final design uses a thin dark contour and twelve correct thirty-degree labels around the fine tick ring, prioritizing clean small-icon typography. Only the selected final raster is packaged.
