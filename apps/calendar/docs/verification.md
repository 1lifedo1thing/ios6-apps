The active Starts/Ends row is blue; portrait pins the picker to the bottom. Landscape places the summary beside the picker to preserve usable height on modern iPhones.

## Icon digit alignment

The icon renderer now centers the visible numeral mask instead of the font's advance width. The static `12` moves 18 pixels left in the 1024-pixel source artwork: its dark-ink margins change from 208/172 pixels to 190/190 pixels. Font size, vertical position, header, and paper shading remain unchanged.

All dates from 1 through 31 were rendered through the same `render_icon` function and inspected in a [contact sheet](screenshots/icon-centering/all-dates.png). [Pixel measurements](screenshots/icon-centering/date-bounds.json) show a maximum dark-ink center error of one source pixel, with no clipping. Antialiased edge thresholds can shift the measured dark core slightly relative to the complete glyph mask. The original uncorrected glyph centers ranged from 59 pixels left to 21 pixels right. The renderer extraction preserves the installed static icon byte-for-byte (SHA-256 `8b8b9e6ecad83363545bc6516991a9556b18e71d7c1366443c52bd0df3327739`). These were artwork validation samples; the installed icon at this verification point was still static `12`. The dynamic-date update below supersedes that behavior.

## Boundaries

Model tests verify the local reminder plan. Actual notification delivery and device calendar-account synchronization have not been tested on a physical iPhone. Pending invitation display is implemented against EventKit; responding and adding invitees require the system calendar because the public API does not allow those writes. Date icons refresh while active or on the next foreground activation, with the simulator limitation documented above. This is an iPhone recreation running on iOS 17+, not an iOS 6 binary or the separate iPad leather interface.
